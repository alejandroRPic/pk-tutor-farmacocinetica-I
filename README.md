# 💊 PK Tutor — Farmacocinética I

> Resuelve problemas de bolo intravenoso monocompartimental con razonamiento guiado.

**▶ [Abrir la app](https://tuusuario.github.io/pk-tutor-farmacocinetica-I/)**

## Qué es

Resuelve problemas de bolo intravenoso monocompartimental con razonamiento guiado.

- Tipo de app: Tutor o simulación
- Español

Elige el modo, el tema y el nivel de ayuda, y comparte el enunciado o tu duda. Resuelve cada paso con el tutor y explica tu razonamiento; puedes pedir más pistas cuando las necesites.

## Cómo se usa

1. Abre la app en el navegador.
2. Pulsa «Configurar clave de OpenAI», pega tu clave y guárdala (solo se almacena en tu navegador).
3. Rellena el formulario y pulsa el botón principal.
